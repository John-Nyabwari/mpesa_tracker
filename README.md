# MPESA Tracker

MPESA Tracker is a Kotlin-based Android application designed to help users monitor, categorize, and analyze their MPESA transactions and expenses. The app provides a simple and effective way to keep track of where money is going, identify spending patterns, and make better financial decisions.

## Purpose

The main purpose of this project is to give users a convenient tool for managing personal finances related to MPESA transactions. Instead of manually tracking expenses across messages, receipts, or notes, users can record and review their spending in one organized place.

## Objectives

This project aims to:

- Track MPESA income and expenses in a structured way
- Help users understand their spending habits over time
- Organize transactions by category, date, or type
- Provide quick insight into monthly and periodic spending
- Promote better financial awareness and budgeting
- Offer a clean, mobile-friendly interface for everyday use

## Key Features

- Record MPESA transactions with details such as amount, date, and description
- Categorize transactions (e.g., food, transport, shopping, bills, savings, entertainment)
- View recent transactions and transaction history
- Summarize spending trends over time
- Help users monitor regular expenses and identify wasteful spending
- Keep financial records accessible from a single app
- Support easy retrieval of past expenses for reporting or budgeting

## Why This Project Matters

Many people use MPESA for daily transactions, but tracking these expenses manually can be time-consuming and error-prone. MPESA Tracker solves this by turning transaction activity into a clear and useful record, helping users stay financially informed and in control.

## Getting Started

### Prerequisites

- Android Studio
- JDK 11 or later
- Android SDK configured for Kotlin development

### Clone the Repository

```bash
git clone https://github.com/John-Nyabwari/mpesa_tracker.git
cd mpesa_tracker
```

### Open in Android Studio

1. Open Android Studio
2. Select "Open an existing project"
3. Navigate to the cloned repository
4. Let Gradle sync the project
5. Build and run the app on an emulator or physical device
